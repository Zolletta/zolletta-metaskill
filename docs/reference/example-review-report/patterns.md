## Recommendations

1. Split `ApiHandler` by domain (service / reconciler / formatter) — highest-leverage change; it also resolves the classes.1/classes.3 violations in `user_manager.py`.
2. Replace both type ladders (`ReportEngine.render`, `OrderProcessor::ship`) with polymorphic dispatch — the report/carrier classes already exist and are nearly empty.
3. Segregate `BroadChannel` and the PHP `Worker` interface; this removes the LSP-breaking `NotImplementedError` stubs for free.
4. Constructor-inject `StripeGateway`/`MysqlOrderRepository` in both `CheckoutService` implementations to restore testability.
5. Add the four missing test mirrors — all four files sit at 0% coverage.
6. Split multi-class files (both languages) so filename ↔ class name holds.
