# Obstacles survey

The [Augmented Coding Patterns](https://lexler.github.io/augmented-coding-patterns/) catalog lists 15 [obstacles](https://lexler.github.io/augmented-coding-patterns/obstacles/) — inherent limitations of LLMs that no prompt or tool can fully eliminate. The review skill cannot *solve* these obstacles (they are properties of the model, not the workflow), but its architecture is designed to *work around* them. This survey marks each obstacle as **addressed** (the architecture mitigates it, with links to evidence), **partial** (mitigated in some cases but not structurally), or **not applicable** (the obstacle doesn't arise in a read-only batch review).

| Obstacle                                                                                                                                                           | Status             | How the architecture addresses it                                                                                                                                                                                                                                                          |
|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [Black Box AI](https://lexler.github.io/augmented-coding-patterns/obstacles/black-box-ai/) — AI's reasoning is hidden; misalignment goes undetected                | **Addressed**      | The scripts-first protocol makes reasoning visible: scanner output is deterministic and inspectable, and the judgment pass must cite it verbatim. [Offload Deterministic](patterns.md#13-offload-deterministic); [Perfect Recall Fallacy audit](anti-patterns.md#9-perfect-recall-fallacy) |
| [Cannot Learn](https://lexler.github.io/augmented-coding-patterns/obstacles/cannot-learn/) — fixed weights, no memory between sessions                             | **Addressed**      | `settings.json` is the project's persistent memory — every run re-reads it. [Ground Rules](patterns.md#9-ground-rules); [Context Management](patterns.md#5-context-management)                                                                                                             |
| [Compliance Bias](https://lexler.github.io/augmented-coding-patterns/obstacles/compliance-bias/) — AI says "sure thing, boss" even for nonsensical requests        | **Not applicable** | The review is not conversational — there is no user request to comply with. Subcommand scopes are fixed ([Focused Agent](patterns.md#8-focused-agent)); the reviewer cannot be talked into narrowing scope. See [Answer Injection audit](anti-patterns.md#3-answer-injection)              |
| [Context Rot](https://lexler.github.io/augmented-coding-patterns/obstacles/context-rot/) — instructions lose influence as context grows                            | **Addressed**      | Each subagent starts fresh with a small, focused context — one SKILL.md, one cache file, one report. [Focused Agent](patterns.md#8-focused-agent); [External Context](patterns.md#6-external-context); [Obsess Over Rules audit](anti-patterns.md#8-obsess-over-rules)                     |
| [Degrades Under Complexity](https://lexler.github.io/augmented-coding-patterns/obstacles/degrades-under-complexity/) — multi-step tasks accumulate errors          | **Addressed**      | The three-phase protocol breaks work into small verifiable steps; each subagent has one scope. [Chain of Small Steps](patterns.md#3-chain-of-small-steps); [Sunk Cost audit](anti-patterns.md#11-sunk-cost)                                                                                |
| [Excess Verbosity](https://lexler.github.io/augmented-coding-patterns/obstacles/excess-verbosity/) — AI overwhelms with unnecessary detail                         | **Addressed**      | Reports are sliced by subcommand; SUMMARY/TODO/specialist-report split; "Do Not Overcomplicate Responses" rule. [Noise Cancellation](patterns.md#12-noise-cancellation); [Cognitive Overload audit](anti-patterns.md#5-cognitive-overload)                                                 |
| [Hallucinations](https://lexler.github.io/augmented-coding-patterns/obstacles/hallucinations/) — AI makes up APIs, methods, or syntax                              | **Addressed**      | Scanner output is deterministic — the LLM cannot report a finding the scripts didn't surface. [Offload Deterministic](patterns.md#13-offload-deterministic); [Perfect Recall Fallacy audit](anti-patterns.md#9-perfect-recall-fallacy)                                                     |
| [Keeping up](https://lexler.github.io/augmented-coding-patterns/obstacles/keeping-up/) — AI generates faster than humans can review                                | **Addressed**      | The review *is* the human's catch-up mechanism — it audits AI-generated code after the fact. [Slice for Review](patterns.md#17-slice-for-review); [Flying Blind audit](anti-patterns.md#7-flying-blind)                                                                                    |
| [Limited Context Window](https://lexler.github.io/augmented-coding-patterns/obstacles/limited-context-window/) — fixed context size; everything competes for space | **Addressed**      | Context is externalized to files (`_context.md`, cache, settings) and loaded on demand per subagent. [External Context](patterns.md#6-external-context); [Context Management](patterns.md#5-context-management)                                                                            |
| [Limited Focus](https://lexler.github.io/augmented-coding-patterns/obstacles/limited-focus/) — attention dilutes when too much is loaded                           | **Addressed**      | One subagent per scope, each loading only its own SKILL.md and cache. [Focused Agent](patterns.md#8-focused-agent); [Distracted Agent audit](anti-patterns.md#6-distracted-agent)                                                                                                          |
| [Negative Bleedthrough](https://lexler.github.io/augmented-coding-patterns/obstacles/negative-bleedthrough/) — negation activates what you want to avoid           | **Not applicable** | The review does not use negative instructions to suppress behavior — it uses positive scope definitions ("review all source code in `src/`") and deterministic scanner output. [Answer Injection audit](anti-patterns.md#3-answer-injection)                                               |
| [Non-Determinism](https://lexler.github.io/augmented-coding-patterns/obstacles/non-determinism/) — same input yields different results across runs                 | **Partial**        | Deterministic scanner output anchors the judgment, but the LLM judgment pass itself is non-deterministic. [Offload Deterministic](patterns.md#13-offload-deterministic); [Determinism boundary](code/determinism.md)                                                                       |
| [Obedient Contractor](https://lexler.github.io/augmented-coding-patterns/obstacles/obedient-contractor/) — quick fixes over maintainability, no pushback           | **Addressed**      | The review *is* the pushback — it flags quick fixes and technical debt. ADR directives enforce decided tradeoffs. [Decision Guards](patterns.md#subsumed-patterns-delivered-by-a-pattern-already-in-use); [Silent Misalignment audit](anti-patterns.md#10-silent-misalignment)             |
| [Selective Hearing](https://lexler.github.io/augmented-coding-patterns/obstacles/selective-hearing/) — AI ignores instructions mid-task                            | **Addressed**      | Rules are loaded fresh per subagent from files, not relied on from conversation history. [Ground Rules](patterns.md#9-ground-rules); [Reference Docs](patterns.md#14-reference-docs); [Obsess Over Rules audit](anti-patterns.md#8-obsess-over-rules)                                      |
| [Solution Fixation](https://lexler.github.io/augmented-coding-patterns/obstacles/solution-fixation/) — AI latches onto the first plausible solution                | **Addressed**      | The reason-to-change test forces exhaustive enumeration before verdict; scanner evidence prevents declaring "found it" without verification. [Constrained Tests](patterns.md#4-constrained-tests); [Unvalidated Leaps audit](anti-patterns.md#13-unvalidated-leaps)                        |
